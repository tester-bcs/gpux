Кто может подключиться

  • Linux + NVIDIA GPU от 8 ГБ (RTX 20xx+; 50xx — идеально)
  • Сеть: машина видит роутер (tailscale/headscale, VPN или LAN)
  • Диск: ~30-50 ГБ под модели (быстрый NVMe — плюс)
  • ОС-зависимости: NVIDIA-драйвер, python 3.10-3.12, git

    • Подключение за 15 минут

    1 Установи WanGP (движок генерации)

    Это и есть движок — Forge-подобное приложение с моделями. Клонируй и поставь:

    git clone https://github.com/deepbeepmeep/Wan2GP.git ~/Wan2GP cd ~/Wan2GP python3 -m venv venv source venv/bin/activate pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu130 pip install -r requirements.txt

    Под свою карту возьми верный CUDA-индекс: 50xx → cu130, 30xx-40xx → cu126/cu128. Подробно: docs/node-setup.md в репо.

    2 Разверни gpux-ноду

    Код ноды + конфиг под твои пути:

    git clone https://github.com/tester-bcs/gpux.git ~/gpux cp ~/gpux/node/config.mini-pc.py ~/gpux/node/config.py nano ~/gpux/node/config.py # поправь WAN2GP_ROOT и venv-путь

    В config.py укажи: WAN2GP_ROOT (куда поставил WanGP), VENV_ACTIVATE, имя хоста в CAPABILITIES.

    3 Запусти и проверь локально

    Первая генерация скачает модели (10-40 ГБ, один раз; докачивается после обрывов):

    bash ~/gpux/node/run.sh # в другом терминале: curl 127.0.0.1:8095/api/status # ждём {"ready":true} — нода жива

    4 Зарегистрируйся в сети (форма ниже)

    Нужен адрес, по которому роутер достучится до твоей ноды: tailscale-IP (100.x), VPN-IP или LAN-IP. Порт 8095.

    Регистрация ноды

    После регистрации нода появится в статусе сети сверху и начнёт получать задачи, когда свободна.

    Частые вопросы

    Что будет с моей машиной, пока она в сети?

    Нода держит модель загруженной и ждёт. Задачи уходят только на свободные ноды — если ты сам чем-то занял GPU, скажи админу, и ноду выведут из ротации. Режим «фарм kudos в простое» — опционален и включается отдельно.

    Видят ли другие мои промпты?

    Промпты и картинки идут напрямую на выбранную роутером ноду внутри доверенной сети (tailscale). В публичные сети ничего не уходит, если не включён режим «draft» (черновик через AI Horde — явный флаг в UI).

    Сколько диска нужно?

    Модели: Flux Klein 4B (~8 ГБ с текст-энкодером), SDXL ~7 ГБ, видео-модели — от 15 ГБ. Планируй 30-50 ГБ под весь набор.

    А если у меня Windows / Mac?

    Windows подходит (WanGP работает), но ноду нужно запускать без systemd — попроси админа помочь с автозапуском. Mac (MPS) — экспериментально, ветка MPS в репо WanGP.

    Я получаю что-то за простой?

    Сейчас — приоритет в очереди и статус в сети. Система учёта (gpu-секунды на пользователя) уже работает, монетизация/токены — на горизонте (см. roadmap в репо).
