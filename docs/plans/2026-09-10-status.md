### Поправки к рекомендациям

1. **`base` во Vite — `'/'` (или `'./'`), НЕ `'/studio/'`.** Фронт на корне поддомена;
   `/studio/` в `vite.config.ts` = все пути к `assets/*.js` → 404, фронт не грузится.
2. **Nginx менять не нужно.** `npm run build` → положить `dist/*` в
   `niceguy:/home/avk/gpux/router/web/`. nginx уже проксирует `/` на роутер, роутер
   отдаёт статику через `StaticFiles`. Никаких `alias`/`try_files`.
3. **Canary** — принцип верный. Механика: старый `index.html` вторым `StaticFiles`-mount
   роутера (`/legacy/`) для мгновенного отката. Не `/studio-legacy/`.
4. **Кеш-хедеры** (`assets/` → `immutable`, `index.html` → `no-store`) — в vhost
   `gpux-studio` на niceguy (`ssh mesh-niceguy`, sudo), не в удалённом vps-ru конфиге.
5. **Не `npm run dev` в прод** — ок.
6. **401** — basic-auth браузер шлёт сам, SSE через него уже работает. «Обработка» =
   на `fetch`→401 показать «перезагрузите/перелогиньтесь», не белый экран.
7. **Видео и flux-dev (Dev) — их НЕТ.** Видео не реализовано (нет модели/дока/`modality:video`);
   flux-dev запаркован до 64 ГБ RAM. `<video muted loop>` — задел на будущее, не требование.
   Сейчас: картинки = только Klein, аудио = sfx + chatterbox.

### Фичевый паритет с текущим `web/index.html` (обязательно)

Новый фронт должен воспроизвести всё, что HTML успел обрасти за сессию:
- `/api/gallery` вместо чтения папок нод; поля на файл: `prompt/seed/steps/mode/modality/kind/duration_s/node`.
- Бейджи промптов на плитках (`c886a0f`) + фолбэк промпта из имени файла.
- Статус ноды человекочитаемо: `.offline` / `swapping` / нехватка VRAM.
- Свап модели: submit отдаёт `{swap:true, eta_s}`, SSE шлёт `{type:"model_swap", from, to, eta_s}`
  → «Loading model to GPU… ~Nс». `/api/capabilities`/`caps` несут `loaded_model`, `model_cost{}`.
- Тумблер **Изображение/Аудио**: select аудио-модели из `caps.model_cost` (`modality:audio`),
  слайдер длительности (скрыт для `kind:tts`).
- Аудио в галерее: `<audio controls preload=none>` в плитках + лайтбоксе; `/api/image/{name}`
  отдаёт wav с `audio/wav` + Range (роутер форвардит `Range` → 206) для скраббинга.
- **Правый клик по плитке → Открыть / Скачать / Удалить** (`DELETE /api/image/{name}[?node=]`).
- img2img: файл → dataURL → `init_image`; «В img2img» из галереи.
- `busy` считать **только по достижимым нодам** (`n.ok`) — иначе кнопка Generate залипает
  в «Генерация…» из-за оффлайн-ноды (фикс `96078ce`).
