## Следующая задача (заказчик назначит) — переезд фронта на React

Бэкенд стабилен (центральная галерея, честный VRAM-чек, img2img) ⇒ переезд «косметический».
Требования заказчика к исполнению:

1. **Canary**: не заменять `/studio/` мгновенно. Старый HTML → `/studio-legacy/`,
   новый по основному адресу. Мгновенный откат при баге в SSE/API.
2. **Синхр. с новыми контрактами**: новый фронт использует `/api/gallery`
   (не чтение папок нод), рисует бейджи промптов (`c886a0f`), показывает статус
   `.offline` ноды человекочитаемо («Нода отключена из-за нехватки VRAM»).
3. **Prod build**: `npm run build` (не dev). Nginx: агрессивный кеш для `assets/`,
   полный запрет кеша для `index.html`. `base: '/studio/'` жёстко в `vite.config.ts`.
4. **Тяжёлые состояния**: статус «Loading model to GPU…» при незагруженной модели;
   для видео-результатов в галерее — `<video autoplay loop muted>`; для аудио — `<audio>`.
5. **Auth**: React корректно обрабатывает 401 (auth на уровне nginx, фронту знать нечего).

Итог: `npm run build` → scp в `web/` роутера niceguy → `location /studio/` (или новый
поддомен) с `alias` + `try_files`.
